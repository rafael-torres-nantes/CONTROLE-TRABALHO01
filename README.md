## 📚 Contextualização do projeto

Repositório contendo exercícios resolvidos e relatórios da disciplina de Controle e Servomecanismos da UFMS. O material abrange a análise de sistemas de controle, respostas ao degrau, redução de polos dominantes e sistemas em malha fechada, visando a aplicação prática dos conceitos teóricos.

## 🛠️ Tecnologias/Ferramentas utilizadas

* Python
* Jupyter Notebook (`.ipynb`)
* Markdown (`.md`) para relatórios
* Bibliotecas: `numpy`, `matplotlib`, `control`, `scipy`, `sympy`

## 📌 Como executar o projeto

Para executar as simulações, certifique-se de possuir Python instalado e as bibliotecas do projeto (`numpy`, `matplotlib`, `control`, `scipy`). Abra os notebooks localizados em `trabalho_01/` ou `trabalho_02/` utilizando o Jupyter Notebook e execute as células sequencialmente para visualizar as análises de resposta de sistemas de controle.
